## Purpose

The guidebook is the official visual companion to the repository. It supports portfolio review, onboarding, teaching, technical demonstrations, LinkedIn presentation, and rapid orientation for developers, data engineers, researchers, instructors, and responsible-AI practitioners.

## Save as PDF

Open the guidebook in a browser, select **Print / Save as PDF**, choose A4 paper, enable background graphics, and save the result. The HTML uses print styles that create one page per guidebook section.
