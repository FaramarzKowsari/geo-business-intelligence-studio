Run the Windows edition

Four simple steps

Download the executable

Use the official GitHub Release link above. Download the accompanying SHA-256 file when you want to verify the binary.

Keep the release files together

Place the EXE and checksum file in a folder you control, such as Downloads\\GeoBusiness.

Double-click the EXE

The application starts a local service and opens the dashboard in your default browser, typically at http://127.0.0.1:8765.

Keep the application window open

Use the browser dashboard while the local application is running. Close the application window when you are finished.

Windows SmartScreen

Why Windows may display an unknown-publisher warning

The executable is distributed from the official GitHub Release but is not currently signed with a commercial code-signing certificate. Windows SmartScreen may therefore show an Unknown publisher warning.

After confirming that the download came from this repository, select More info, then Run anyway. For additional assurance, compare the executable's SHA-256 hash with the published checksum file.
