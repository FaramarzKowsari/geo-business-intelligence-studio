Why this repository exists

From scattered place records to an inspectable data workflow

Most local-business research starts with inconsistent records, missing contact fields, repeated entries, unclear provenance, and a temptation to depend on expensive or opaque services. This project turns that problem into a transparent workflow whose core remains useful without paid AI or a proprietary data key.

01

Discover

Search fictional offline samples, OpenStreetMap data, or the official Google Places API through a shared provider interface.

02

Normalize

Convert provider-specific responses into a common business record with source attribution and consistent fields.

03

Evaluate

Remove probable duplicates, score data completeness, map locations, analyze coverage, and export CSV or JSON.

Deterministic by default

Search, normalization, quality scoring, duplicate detection, mapping, and export work without an AI model. The built-in briefing remains available when AI is disabled.

Optional intelligence layer

Users may connect Ollama locally or an OpenAI-compatible endpoint with their own credentials. No project-owned API secret is committed.

Provider boundaries

External services are hidden behind adapters, so data sources can be replaced or extended without rewriting the user interface and core orchestration.

Responsible data use

The repository avoids Google Maps website scraping, CAPTCHA bypass, identity rotation, and access-control evasion. Provenance and verification warnings remain visible.
