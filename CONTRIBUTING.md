# Contributing

1. Fork the repository and create a focused branch.
2. Keep adapters isolated behind the `BusinessProvider` interface.
3. Add tests for new behavior.
4. Run `pytest` before opening a pull request.
5. Never contribute secrets, copied proprietary datasets, access-control bypasses, CAPTCHA solvers, or identity-evasion features.
6. Update documentation when behavior or configuration changes.

By contributing, you agree that your contribution is licensed under the MIT License.
